📋 CSV Schema & Required Headers

Ensure your CSV file contains the following column header row:

roll_no,full_name,email,parent_email,phone,department_code,semester,section
  • roll_no (Required): Unique student roll / identification number.
  • full_name (Required): Full name of the student.
  • email (Required): Student's official email address for receiving attendance notices.
  • department_code (Required): Department code (e.g. CSE, IT, ECE, MECH). Automatically created if new.
  • semester (Optional, default 1): Numeric integer (1 through 8).
  • section (Optional, default A): Class section letter.
  • parent_email (Optional): Parent/guardian email for automatic absence notifications.
